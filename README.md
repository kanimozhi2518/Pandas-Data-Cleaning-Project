# Online Shopping Data Cleaning and Analysis

## Project Overview
This project focuses on cleaning and analyzing an Online Shopping dataset using Python. The dataset was preprocessed by handling missing values, removing duplicate records, correcting inconsistent data formats, and preparing the data for accurate analysis and reporting. The project demonstrates essential data preprocessing techniques required for real-world data analytics.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Google Colab

## Dataset
The project uses an Online Shopping dataset containing customer transactions, product information, pricing, quantities, and sales-related records.
